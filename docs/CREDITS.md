# Источники данных и изображений

Фотографии артистов в В2 грузятся из сети: Викиданные (свойство P18 у элемента
с MBID исполнителя) дают имя файла на [Викискладе](https://commons.wikimedia.org/),
приложение показывает его миниатюру 330px. Локальных снимков из В1 больше нет.
Лицензии свободные, автор и условия — на странице файла на Викискладе.
Нет фото в Викиданных — плитка рисуется буквой на градиенте.

Данные каталога — имена, страны, даты, теги, дискографии — из
[MusicBrainz](https://musicbrainz.org/), лицензия базы CC0.

## Тексты справок

Справка «Об исполнителе» — первый абзац статьи Википедии, поля `Artist.biography`
(английская) и `Artist.biographyRu` (русская). Русская — не перевод английской:
у русской Википедии свои авторы и своя редакция. Лицензия текста —
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), авторы указаны
в истории правок статьи.

Из MusicBrainz этот текст не приходит: тамошний `annotation` — служебная заметка
редакторов базы, а не справка для читателя. Справка грузится при открытии
детали в два шага: у записи MusicBrainz есть связь с Викиданными
(`inc=url-rels`), у элемента Викиданных — ссылки на статьи (`wbgetentities`),
у Википедии — `REST /page/summary/{title}`.
